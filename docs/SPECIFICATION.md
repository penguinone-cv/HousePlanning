# HousePlanning v1 仕様書

承認済み計画に基づく。Windows 11 x64、日本語、オフライン、自分用・複数住宅。目的は空間・配置・内外観の確認。

## 操作
- 左に編集ツール、中央に2D図面または3D、右に選択要素の数値編集。単位はmm。
- PDFページ / PNG / JPEGを下敷きにする。2点と既知寸法で校正。切り抜き、90度回転、透過度、原点移動。階ごとに独立した下敷きを保持。
- 直線壁を2点で作成。床・部屋・吹き抜け・敷地は多角形（左クリックで頂点、Enterで完了）。窓・扉は壁をクリック。その他のパーツは中心をクリック。
- 端点・グリッド吸着。選択後のドラッグ、数値編集、複製、削除、Undo/Redo。開口部は壁IDと壁始点からの距離に従属。
- 2階建て、吹き抜け、直階段・折返し階段、手すり、バルコニー。屋根は陸・片流れ・切妻の矩形パーツの組合せ。床の穴は吹き抜け多角形として同じ階の床から除去。
- 標準パーツ：机、椅子、ソファ、ベッド、収納、キッチン、浴槽、洗面台、トイレ、車、塀、駐車場。幅・奥行・高さ・角度・色を変更。
- 3D：周回、自由飛行、一人称歩行、階の表示切替、屋根非表示、視点保存・復帰、PNG撮影。歩行は壁・床に衝突し階段移動可能。
- 環境光・太陽光・簡易室内灯。標準/低品質切替。日時による日照計算は対象外。

## データと初期値
天井高2400、階高2800、外壁厚200、内壁厚100、グリッド910。仮値であり図面から自動認識しない。高さ・壁厚は編集可能。
編集データのみが正本。mmからmに変換して3D生成。GUIDで各要素を参照。
`.houseplan`はversion付きJSON＋下敷き画像のZIP。テンポラリ書込後置換、前回バックアップを作成。復元失敗時は現在の編集状態を変更しない。元PDFへの参照を保存の必須条件にしない。
不正多角形、壁外/重複開口、ゼロ以下の寸法は拒否して説明する。読み込み画像は長辺4096px以下に制限。PDFは選択ページだけ描画。暗号化・破損ファイルを明示的に拒否。

## 完成条件
PDF3ページの選択・校正、壁変更に追従する開口、吹き抜け・階段・窓の3D表現、寸法/Undo/保存復元一致、元資料なしの再編集、Windows配布物での起動。
架空の2階建てサンプルを同梱。提示された個人図面をリポジトリ/配布物へ含めない。
150m2程度・2階・家具設備100個、1080p標準で平均60fpsかつ95%フレーム22ms以内をRTX2070Super実機で目標。実機がなければ未検証として報告。

## 除外
OCR/自動図面認識、外部3Dモデル、敷地高低差、正確な日照解析、メーカー部品忠実再現、フォトリアル生成、クラウド、提示住宅の入力済モデル。
