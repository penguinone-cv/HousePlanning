# HousePlanning

Windows 11用の、間取り図から内観・外観を確認するオフラインアプリです。PDF・PNG・JPEGを下敷きにして壁・窓・家具を配置し、3D空間を歩けます。

## 起動

`HousePlanning-win-x64.zip`をフォルダーに展開し、`HousePlanning.exe`を起動してください。EXEだけを別の場所へ移動せず、`data_HousePlanning_windows_x86_64`、`HousePlanning.pck`、`pdfium.dll`を同じフォルダーに置いてください。Godotや.NETを別途インストールする必要はありません。

- Windows 11 x64、キーボードとマウス。日本語フォントはWindows標準フォントを使用します。
- RTX 2070 SUPERで1920×1080・標準品質を検証。計測条件と結果は開発版の `docs/REVIEW.md` を参照してください。
- アカウント・ネット接続は不要です。図面と住宅データは外部へ送信しません。
- 起動時は架空の2階建て住宅を表示します。「新規」で空の住宅、「サンプル」で元のサンプルに戻れます。

## 図面から作成する

1. 「新規」を押し、「1階」を選びます。
2. 「図面取込」でPDF・PNG・JPEGを選びます。PDFはページを選択して読み込みます。
3. 寸法がわかる線の両端をクリックし、実寸を **mm** で入力します。読み込み後は「全体表示」で図面全体を表示できます。
4. 必要なら左の「図面調整」で切り抜き、90度回転、原点指定を行います。右側で図面の位置や透過度を調整できます。
5. 「壁」を選んで始点・終点をクリックします。「床」で輪郭の頂点をクリックし、Enterで確定します。壁だけでは床は生成されません。
6. 「窓」「扉」を選び、配置する壁をクリックします。位置・幅・高さは選択後、右側で変更します。扉は開いた状態で表示し、通り抜けできます。
7. 「2階」でも図面を取り込み、同じ建物の基準点を原点に合わせます。各階の床高さ・天井高・階高は右側で設定します。
8. 2階の「吹き抜け」で、床を抜く範囲を多角形として指定します。階段の上端まで穴を設け、上階に着地する床を残してください。
9. 家具・屋根・外構を配置して「保存」。別の案は「別名で保存」で残せます。

高さや屋根形状は平面図から自動認識しません。初期値（天井2400mm、階高2800mm、壁厚200mm、グリッド910mm）は図面に合わせて変更してください。内壁は壁厚100mmなどに変更できます。1階の厚い壁（180mm以上）は、2階床まで外壁の幕板部分も生成します。

## 編集と3D操作

| 操作 | 方法 |
| --- | --- |
| 図面の移動・拡大 | 中ボタンドラッグ・ホイール |
| 選択・移動 | 「選択 / 移動」でクリック・ドラッグ |
| 寸法・色・素材 | 右のプロパティ。数値はEnterで確定 |
| 吸着 | 上の「吸着」でグリッド・壁端点への吸着を切替 |
| 多角形 | 頂点をクリック→Enter、右クリックで取消 |
| 複製・削除 | 選択後、右のボタン / Delete |
| 元に戻す・やり直し | Ctrl+Z / Ctrl+Y |
| 保存 | Ctrl+S |
| 外観 | 左の「外から見る」。右ドラッグで回転、ホイールで距離変更 |
| 室内 | 左の「この階を歩く」。WASDで移動、右ドラッグで視線変更 |
| 自由飛行 | WASD、Qで下降・Eで上昇、Shiftで高速移動 |
| マウス解放 | Esc |
| 内部を俯瞰 | 「屋根を表示」を解除し、「選択階だけ表示」を有効化 |
| 視点 | 「視点を保存」。右の保存視点一覧から復帰可能 |
| 画像保存 | 「PNG撮影」。3D時は表示中の空間のみ保存 |

左のパネルは縦にスクロールできます。屋根は2D図面で**外周付近**をクリックして選択します。部屋ツールは名前と範囲を示すためのもので、壁や床は別に作成します。階の高さを変えた場合、既存の階段の高さも合わせて変更してください。非表示設定は表示のみを切り替え、衝突形状は保持します。

窓・扉が壁からはみ出したり重なったりする変更、自己交差した床は拒否し、画面下に理由を表示します。数値入力が反映されない場合はこのメッセージを確認してください。

## 保存と制限

`.houseplan`に編集データと下敷き画像をまとめて保存します。元のPDF・NASがなくても再編集できます。上書き前の内容は同じ場所の`.houseplan.bak`に保存されます。復旧時はバックアップをコピーし、拡張子を`.houseplan`にして開いてください。編集履歴そのものはアプリ終了時に破棄されます。

- PDFはページを画像として読み込みます。暗号化PDFは解除してから使用してください。PDF上限128MB、画像は長辺4096pxへ縮小します。
- 住宅は2階まで。壁は直線、屋根は矩形の陸・片流れ・切妻パーツを組み合わせます。
- 家具は寸法変更可能な基本形です。メーカー製品の忠実な再現、外部3Dモデル読込、自動図面認識、敷地高低差、日時指定の日照解析は含みません。
- 材料と照明は空間確認向けの簡易表現です。建築の設計・構造計算機能ではありません。

## 開発

.NET SDK **9.0.310**、Godot **4.4.1 .NET**、PDFium **Chromium 7999**を使用し、アプリは.NET **8.0.23**向けにビルドします。Python 3.12以上を用意して実行してください。

```powershell
python scripts/bootstrap.py
./scripts/build.ps1 -Test
./scripts/build.ps1 -Export
```

配布先は`dist/HousePlanning-win-x64.zip`です。ビルド用依存物は`.tools`、検証用ユーザーデータは`tmp/appdata`に保存します。Godotエディターで開く場合は`src/App/project.godot`を指定してください。

```powershell
# 配布物でも実行可能な検証コマンド
./dist/HousePlanning/HousePlanning.exe --headless -- --self-test
./dist/HousePlanning/HousePlanning.exe -- --benchmark
./dist/HousePlanning/HousePlanning.exe -- --capture
```

性能測定は5秒ウォームアップ後、屋外・1階・2階を計30秒描画します。`%APPDATA%/Godot/app_userdata/HousePlanning/benchmark.txt`と`frames.csv`へGPU・解像度・結果を出力します。`--capture`は編集・外観・内観のPNGを同じ場所へ出力し終了します。
